# EasyFiles

Self-hosted обмен файлами: поднимаете сервер один раз — и делитесь файлами по локальной сети и интернету. Без регистрации, без облаков, файлы лежат только на вашей машине.

**v2.0 — полная переделка:** новый интерфейс, автоудаление по таймеру, пароли с хэшированием, лимит скачиваний, QR-коды и админ-панель.

## Возможности

- 📤 Загрузка любых файлов **до 2 ГБ** drag & drop или через выбор
- 🔗 Ссылка вида `/download/<id>` — работает в локальной сети и в интернете
- ⏱ **Срок хранения**: 1 час / 24 часа / 7 дней / бессрочно — файлы удаляются автоматически
- 🔒 **Пароль** на файл (хэшируется через scrypt, в открытом виде не хранится)
- 📉 **Лимит скачиваний** — файл «самоуничтожается» после N скачиваний
- 📱 **QR-код** для мгновенной передачи ссылки на телефон
- 🛡 **Админ-панель** `/admin` — все файлы, размер хранилища, удаление
- 🗑 Токен удаления: удалить файл может только тот, кто его загрузил (и админ)
- 🚦 Rate limiting на загрузку и скачивание, защита от удаления чужих файлов
- 🌐 Показ адресов в локальной сети при старте сервера

## Быстрый старт

Нужен [Node.js](https://nodejs.org) 20+.

```bash
git clone https://github.com/brick-i/-easy-files
cd -easy-files

npm run install-all   # ставит зависимости сервера и клиента
npm run build         # собирает клиент
npm start             # запускает сервер на http://localhost:3001
```

Откройте [http://localhost:3001](http://localhost:3001) — готово. Адреса для доступа из локальной сети сервер напечатает в консоли при запуске.

Проверить, что всё работает, можно смоук-тестом (27 проверок API):

```bash
node scripts/smoke-test.js http://localhost:3001 мой-admin-ключ
```

### Режим разработки

```bash
npm run dev           # сервер + Vite dev-сервер с hot reload
```

## Настройка (переменные окружения)

| Переменная        | По умолчанию | Описание                                      |
| ----------------- | ------------ | --------------------------------------------- |
| `PORT`            | `3001`       | Порт сервера                                  |
| `HOST`            | `0.0.0.0`    | Адрес, который слушает сервер                 |
| `PUBLIC_BASE_URL` | —            | Публичный адрес для ссылок (если за прокси/доменом) |
| `ADMIN_KEY`       | —            | Ключ админ-панели (без него `/admin` отключена) |
| `MAX_FILE_SIZE_MB`| `2048`       | Максимальный размер файла в МБ                |
| `DATA_DIR`        | `./data`     | Папка для файлов и метаданных                 |
| `SWEEP_INTERVAL_MS`| `30000`     | Как часто проверять просроченные файлы        |

Пример запуска с настройками:

```bash
PORT=8080 ADMIN_KEY=my-secret PUBLIC_BASE_URL=https://files.example.com npm start
```

## Выход в интернет

Варианты проброса сервера наружу:

1. **Порт-форвардинг** — пробросьте порт роутера на сервер и укажите `PUBLIC_BASE_URL=https://ваш-ip:порт`
2. **Обратный прокси** — Nginx/Caddy + домен (рекомендуется, даёт HTTPS)
3. **Туннель** — Cloudflare Tunnel, ngrok и т.п. без белого IP:

```bash
cloudflared tunnel --url http://localhost:3001
```

## API

| Метод   | Путь                  | Описание                                   |
| ------- | --------------------- | ------------------------------------------ |
| `POST`  | `/api/upload`         | multipart: `file`, `ttl` (сек, 0 = ∞), `password`, `maxDownloads` |
| `GET`   | `/api/file/:id`       | Информация о файле                         |
| `POST`  | `/api/verify/:id`     | Проверка пароля (`{password}`)             |
| `POST`  | `/api/download/:id`   | Скачивание (`password` в теле)             |
| `DELETE`| `/api/file/:id`       | Удаление (заголовок `x-delete-token` или `x-admin-key`) |
| `GET`   | `/api/admin/files`    | Список файлов (заголовок `x-admin-key`)    |
| `GET`   | `/api/health`         | Состояние сервера                          |

## Структура

```
├── server/          # Express-сервер
│   ├── index.js     # входная точка
│   ├── config.js    # переменные окружения
│   ├── routes/      # API файлов и админки
│   └── lib/         # хранилище, безопасность, автоочистка
└── client/          # React (Vite)
    └── src/
        ├── components/  # страницы и UI
        ├── lib/         # API-клиент, форматирование
        └── styles/      # дизайн-система
```

Данные хранятся в `data/uploads` (файлы) и `data/meta` (метаданные JSON). Для бэкапа достаточно скопировать папку `data`.
